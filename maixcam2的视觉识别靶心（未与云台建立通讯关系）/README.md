# MaixCAM2 靶纸识别

在 MaixVision 中打开 `target_detector.py` 并点击 **Run**。程序会实时识别相机画面中的红色同心圆靶纸；当前配置保持 320×240，避免 `find_rects` 耗尽快速帧缓冲，并接受更小的远距离目标框。

- 黄色四边形：经多帧平滑后的目标框；它采用边缘检测，不依赖外框必须是纯黑色，因此打印后偏灰也可以检测。
- 青色十字：黑框的中心，也就是靶心的稳定输出坐标。

首次测试请让纸张基本正对相机、整张靶纸尽量位于画面内、背景不要有大块红色。MaixVision 预览的截图和终端日志可以直接发回本对话继续调参。

## 调参顺序

1. `FRAME HOLD`：当前帧没有测到框时，程序短暂沿用最近稳定的结果，避免闪烁。这不是新的测量值。
2. 没有黄色框：将 `FRAME_EDGE_THRESHOLD` 从 `2400` 降到 `1800`；误识别背景矩形则升到 `3200`。
3. 靶纸离相机很远：可继续将 `MIN_FRAME_WIDTH` 从 `24` 降至 `18`。如果靶框低于约 30 像素宽，软件调参的可靠性会明显下降，应采用更窄视场角的镜头或将相机安装得更近。

这个程序的主调试画面通过 `disp.show(img)` 发到 MaixVision，可用暂停按钮冻结单帧再观察颜色与框的位置。
