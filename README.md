# H题小球平衡装置

当前版本使用串级双环 PID：MaixCAM2 识别小球位置和速度，通过独立串口发送给 MSPM0G3507；位置外环根据目标点与当前位置生成目标球速，速度内环根据速度误差生成摆杆目标角，最后由 MS42CG 编码器角度执行层控制 D36A 和步进电机。

位置外环带有距离制动曲线、目标速度加速限制和目标点跨越复位；远离目标时允许快速运动，靠近目标时提前降低目标速度。速度内环带有摆角限幅、积分限幅、更快的制动摆角斜坡和自动破静摩擦补偿，用于消除小球未到目标便停住的问题并抑制过冲。

当前视觉端按稳定的 `20ms` 周期发送，主板闭环启动确认缩短到2帧，并提高目标速度、摆角和步进脉冲的建立速度。最大球速保持 `20cm/s`；位置环制动参数按实测机构的正负方向分别设置。

## 目录

- `MSPM0G3507/`：3507主板、MS42CG PWM编码器、D36A步进电机驱动和视觉外环 PID代码。
- `MaixCAM2/`：MaixCAM2小球检测、位置标定、滤波和 UART数据发送代码，包含当前模型。

## 当前通信与接线

- MaixCAM2 `B2/UART3_TX` → MSPM0G3507 `B16/UART2_RX`
- MSPM0G3507 `B15/UART2_TX` → MaixCAM2 `B3/UART3_RX`（当前可选）
- 两块板 `GND` 必须共地，串口参数为 `115200 8N1`
- MS42CG `PWM` → MSPM0G3507 `B10`
- D36A `ST1/STEP1` → `B12`，`DIR1` → `B13`，`EN1` → `B8`

## 控制状态

- `Z`：在机构水平位置设置角度零点
- `E`：使能电机
- `V`：进入视觉 PID闭环
- `X+5` / `X-5` / `X0`：设置小球目标位置，单位 cm，范围 `-10.00~+10.00cm`
- `M`：退出视觉闭环并回到手动水平模式
- `S`：紧急停止并关闭电机使能

视觉丢球、串口超时、编码器失效或角度越界时，3507执行安全保护。手动 `P+`/`P-` 仍是独立的破静摩擦测试命令；视觉 PID 另有自动补偿：位置误差超过 `0.60cm`、速度连续3帧不高于 `0.30cm/s` 时，按运动方向短暂补足启动角；检测到同向位移达到 `0.05cm` 或同向速度达到 `0.30cm/s` 后立即退出。若小球再次停在误差范围外，系统会再次微调，目标是把静态误差约束在 `0.60cm` 内并为1厘米指标保留余量。

编码器输入会拒绝不属于约971Hz/486Hz两种PWM周期的帧，以及相邻有效帧之间超过 `3.00deg` 的不可能角度跳变。若新的绝对角仍处于 `121~208deg` 软限位内、连续3帧彼此一致且相对旧基准的跳变不超过 `25.00deg`，程序会自动重新同步编码器基准，并先把电机目标冻结在确认后的物理角度；下一帧视觉数据再通过原有角度斜坡恢复控制，避免一次真实位置变化造成 `reject` 永久累加。绝对软限位必须连续5个有效样本越界才会触发失能。状态输出中的 `fault` 会锁存最近故障（`0`正常、`1`编码器丢失、`2`绝对角、`3`相对角、`4`方向），`reject` 是累计拒绝数，`absbad` 是当前连续越界数，`rsync` 是自动重同步次数，`rcand` 是当前候选连续帧数。

电机首次使能时，转子可能吸合到最近的电气位置并使横杆轻微跳动。方向保护不会再把这段非STEP位移作为检测基准，而是在第一个实际STEP命令开始时记录误差；因此首次 `E` 可以自动把横杆拉回零点，不再需要重复发送使能命令。实际STEP方向错误时，原有约50ms方向检测和自动失能仍然保留。

摄像头 UART2 和无线 UART1 的接收仍由中断采集，主循环只解析已经收到的数据。无线调试发送改为1KB队列：电机使能时每轮最多发送2字节，RTS忙时立即跳过，不再在实时控制路径中等待最长约100ms；电机关闭时每轮最多发送8字节。状态中的 `txdrop` 表示队列空间不足而整条丢弃的调试消息数。上电说明和停机后的 DLOG 导出仍会完整发送。

## 串级 PID 与 A→B 测试

初始参数为：位置环 `Kp=3.50, Ki=0.08`；向X正方向运动使用
`Kd=0.30、制动减速度=9cm/s²`；向X负方向使用
`Kd=0.40、制动减速度=15cm/s²`。只有S1写死的比赛配置在左行阶段使用
独立的 `Kd=0.55`，让小球在进入S1左端合格区前稍早减速。速度环为
`Kp=0.80, Ki=0.10, Kd=0.03`。目标球速限制为 `20cm/s`，速度给定加速率为
`200cm/s²`，速度环摆角限制为 `±8deg`。这些是带安全限幅的硬件参数，实际装置仍需根据轨道摩擦、负载和相机速度噪声整定。

自动破静摩擦采用自适应启动角：小球向X正方向运动从 `-4.60deg` 开始，向X负方向运动从 `+4.80deg` 开始；一次补偿持续12个视觉帧仍无同向位移时，下一次增加 `0.25deg`，最大限制为 `±6.50deg`。一旦检测到同向位移 `0.05cm` 或同向速度 `0.30cm/s`，立即撤掉强制角度并恢复正常速度环和距离制动；若最大角仍无法启动，则停止重复补偿，重新发送目标或重启视觉闭环后才会重试。状态输出中的 `kick` 表示当前补偿状态，`events` 是触发次数，`boost` 是最近一次自适应启动角，`retry` 是升级级别，`block=1` 表示达到最大角仍未运动。

建议先做短距离测试：机构调平后依次发送 `Z`、`E`，用 `X-3` 设置 A 点并发送
`V`；小球在 A 点稳定后发送 `X+3`，观察 A→B 的加速、提前制动和停止过程。
确认方向与制动正确后再逐步扩大目标距离。任何异常立即发送 `S`。

长距离目标切换（初始距离至少2cm）使用落点锁定：制动后第一次进入目标
`±0.95cm`，随后速度降到 `0.50cm/s` 以下，或位置从本次最佳点回退 `0.05cm`、
速度不超过 `2.00cm/s` 且误差仍小于 `1.00cm` 时，状态变为 `ctrl=HOLD`。位置回退判据用于规避视觉
速度滤波的滞后。进入 `HOLD` 后停止静摩擦强制重试，并切换为安静的软闭环：位置
修正速度限制为 `±1.50cm/s`，保持角限制为 `±4.00deg`，由速度积分自动学习机构
实际需要的支撑角，不再假定编码器相对零度就是物理平衡角。发送下一条 `X` 指令会自动解除 `HOLD` 并开始下一段运动。X正方向误差超过
`1.20cm` 时恢复普通闭环；X负方向根据实测回弹把恢复阈值放宽到 `1.60cm`，
使HOLD有时间把已经进入过合格窗口的小球拉回。该逻辑目的是保留已经进入1cm范围的首次
落点，避免停住后被静摩擦补偿再次拉走。

如果由位置回退触发落点锁定，HOLD最初使用目标方向接球角，抵消视觉速度滤波
尚未反映出的反向回滚。X正方向针对 `X+5` 的新验收窗口（回落不低于 `4cm`、
峰值不超过 `6cm`、最终保持 `4.5～6cm`），首次接球最多瞬时使用
`4.60deg、500ms`，到达目标前 `0.40cm` 时提前撤销。X负方向根据自动往返
实测从 `-4.52cm` 回弹到 `-3.64cm` 的现象，改为最多 `+6.50deg、500ms`，
进入目标前 `0.40cm` 时提前撤销。

如果X正方向接球结束后静止位置仍低于目标前 `0.45cm`，HOLD会执行受限补位：
第一次使用 `4.60deg`；若一次 `240ms` 尝试没有产生位移，下一次依次提高
`0.20deg`，最大 `5.40deg`。检测到向右移动 `0.05cm` 或速度达到 `0.30cm/s`
便立即撤角，但保留已经奏效的补位等级，并立即加载 `2.50deg` 速度积分支撑，
避免角度掉回弱比例输出后再次回滚；间隔约 `100ms` 后再判断，总计最多16次。
达到最终窗口或开始新的目标指令时再复位补位等级。超过目标 `0.40cm` 时切换到
反向保护，回到目标后 `0.20cm` 内解除。实时状态中的 `catch` 是剩余接球帧数，
`trim=活动/次数` 表示补位状态，`guard` 表示上限保护；常态软闭环仍限制为
`±4.00deg`。

X负方向也使用同一套带位移撤销的HOLD补位状态机，但保留独立的机构参数：
补位角从 `+6.50deg` 开始，无位移时每次增加 `0.25deg`，最高 `+8.00deg`；
向左移动 `0.05cm` 或速度达到 `-0.30cm/s` 后立即撤角并加载反向支撑积分。
如果越过负方向目标 `0.40cm`，则用 `-4.60deg` 将小球拉回；检测到向右移动
`0.05cm` 时立即撤角，并在回到目标后 `0.20cm` 以内之前禁止立即重复触发；
原有位置退出条件继续作为备用保护，
避免持续反推造成 `-5cm→-3cm` 的大幅回弹。X正方向已有参数不变。

## 通用 A：自动 O→+5cm→-5cm 测试

在电机已使能、视觉闭环显示 `ACTIVE`，且小球位于O点 `±0.50cm`、速度不超过
`0.50cm/s` 时发送 `A`。主板自动将目标设为 `+5.00cm`；右端首次进入
`±1.00cm` 落点窗口后立即记录转向点，再使用通用PID和 `-5.00cm` 单点目标。
这个入口不启用S1的 `-5.20cm` 偏置、终点区间控制或专用 `Kd=0.55`，可以作为
后续任务配置新状态和新PID参数的基础。

串口会输出：

```text
AUTO START: generic O->+5.00cm->-5.00cm, limit=5000ms
AUTO TURN: x=+...cm err=...cm t=...ms; target=-5.00cm
AUTO PASS: right_err=...cm left_err=...cm turn=...ms total=...ms
```

通用A只有两端误差都不超过 `1.00cm` 且总时间不超过 `5000ms` 才输出
`AUTO PASS`；
超过5秒会先报告超时，但仍继续控制到负方向终点以便诊断。手动发送 `X`、`M`
或 `S` 会取消自动流程。

## S1单键比赛模式

主板板载 `S1/KEY1`（引脚 `A30`）用于不连接电脑的比赛启动。上电后电机和视觉闭环保持关闭；先启动摄像头程序、手动把横杆摆平，并将小球静止放在O点 `±0.50cm` 内，然后短按并松开一次 `S1`。主板会依次自动完成：

S1使用独立的写死比赛配置：右端仍为 `+5.00cm`，左行内部目标为 `-5.20cm`，
左向位置微分为 `Kd=0.55`。小球到达 `-4.40cm` 后由S1终点状态单独接管，
加入 `+2.80deg` 静止支撑和速度阻尼，常态输出限制为 `-2.50～+4.00deg`。
到达 `-5.85cm` 时用 `-3.00deg` 防止越过 `-6.00cm`；若回弹超过
`-4.50cm`，用 `+6.50～+8.00deg` 的短促启动角恢复，左移 `0.05cm` 立即撤角。
位置保持在 `-6.00～-4.50cm`、速度低于 `0.30cm/s` 并连续8个视觉帧后完成。
这些状态和参数只在S1启动后有效，串口 `A`、手动 `X` 以及后续任务不会复用。

1. 把当前横杆角度记录为水平零点；
2. 使能电机，并等待首次吸合跳动自动回到 `±0.15deg`；
3. 连续约100ms确认横杆、小球和摄像头数据稳定；
4. 开启视觉双环PID并等待 `ACTIVE`；
5. 再等待 `400ms` 供操作者释放按键并移开手，然后自动执行 `O→+5cm→左端合格区`。

准备期间小球如果离开O点或仍在运动，倒计时不会启动；倒计时期间小球被碰动，程序会返回等待状态，重新稳定后再倒计时。运行中的短按会被忽略，避免误触重新开始。任何阶段长按 `S1` 约1秒都会取消自动流程并关闭电机使能；完成后系统继续保持在 `-6.00～-4.50cm`，长按后才释放电机。

比赛版应采用完全断电冷启动验证，不向串口发送任何命令，只把串口作为观察日志使用。正常顺序应依次看到 `S1 PREP`、`S1 READY`、`S1 START`、`S1 TURN`、`AUTO PASS` 和 `S1 COMPLETE`。

## 运动数据测试日志

发送 `D1` 开启约25Hz测试记录。运行期间数据只写入主板RAM，不发送长串口日志，因此不会用阻塞式无线输出干扰PID时序；最多保存896个样本，约36秒。开启后原有长状态输出暂停。推荐在视觉闭环已经进入 `ACTIVE` 后记录：

```text
D1
X+5
X-5
X+5
X-5
X+5
X-5
S
D0
```

`S` 先关闭电机，随后 `D0` 才安全地导出CSV。若在电机仍使能时先发送了 `D0`，记录会停止但不会导出；再发送 `S` 和第二次 `D0` 即可。导出期间串口发送是阻塞的，所以必须保持电机失能。
每次发送新的 `X+5` 或 `X-5` 后，观察画面并等待小球停止或明显无法继续运动，再发送下一条目标指令；不要一次性连续粘贴全部目标命令。

CSV表头为：

```text
D,t,seq,valid,x,v,xref,ex,vref,angle,rel,step,kick,block,hold,plim,slim,fault
```

除时间、序号和状态字段外，位置、速度和角度均为 `x100` 整数，例如 `x=-406` 表示 `-4.06cm`。保存完整串口文本后可用于离线计算正负方向启动角、加速度、制动距离、过冲和最终误差。

## 版本与回退

3507和 MaixCAM2代码使用两个独立提交保存：

- 只回退3507：对3507提交执行 `git revert <commit>`
- 只回退 MaixCAM2：对 MaixCAM2提交执行 `git revert <commit>`
- 全部回退：按从新到旧顺序分别 `git revert` 两个提交

推荐使用 `git revert` 生成可追踪的回退记录，不使用破坏历史的强制重置。
