# H题小球平衡装置

当前版本使用串级双环 PID：MaixCAM2 识别小球位置和速度，通过独立串口发送给 MSPM0G3507；位置外环根据目标点与当前位置生成目标球速，速度内环根据速度误差生成摆杆目标角，最后由 MS42CG 编码器角度执行层控制 D36A 和步进电机。

位置外环带有距离制动曲线、目标速度加速限制和目标点跨越复位；远离目标时允许快速运动，靠近目标时提前降低目标速度。速度内环带有摆角限幅、积分限幅、更快的制动摆角斜坡和自动破静摩擦补偿，用于消除小球未到目标便停住的问题并抑制过冲。

当前视觉端按稳定的 `20ms` 周期发送，主板闭环启动确认缩短到2帧，并提高目标速度、摆角和步进脉冲的建立速度；位置/速度PID增益、最大球速和距离制动曲线保持不变。

## 目录

- `MSPM0G3507/`：3507主板、MS42CG PWM编码器、D36A步进电机驱动和视觉外环 PID代码。
- `MaixCAM2/`：MaixCAM2小球检测、位置标定、滤波和 UART数据发送代码，包含当前模型。

## 当前通信与接线

- MaixCAM2 `B2/UART3_TX` → MSPM0G3507 `B16/UART2_RX`
- MSPM0G3507 `B15/UART2_TX` → MaixCAM2 `B3/UART3_RX`（当前可选）
- 两块板 `GND` 必须共地，串口参数为 `115200 8N1`
- MS42CG `PWM` → MSPM0G3507 `B10`
- D36A `ST1/STEP1` → `B12`，`DIR1` → `B13`，`EN1` → `B8`

## 控制状态

- `Z`：在机构水平位置设置角度零点
- `E`：使能电机
- `V`：进入视觉 PID闭环
- `X+5` / `X-5` / `X0`：设置小球目标位置，单位 cm，范围 `-10.00~+10.00cm`
- `M`：退出视觉闭环并回到手动水平模式
- `S`：紧急停止并关闭电机使能

视觉丢球、串口超时、编码器失效或角度越界时，3507执行安全保护。手动 `P+`/`P-` 仍是独立的破静摩擦测试命令；视觉 PID 另有自动补偿：位置误差超过 `0.60cm`、速度连续3帧不高于 `0.30cm/s` 时，按运动方向短暂补足启动角；检测到同向位移达到 `0.05cm` 或同向速度达到 `0.30cm/s` 后立即退出。若小球再次停在误差范围外，系统会再次微调，目标是把静态误差约束在 `0.60cm` 内并为1厘米指标保留余量。

编码器输入会拒绝不属于约971Hz/486Hz两种PWM周期的帧，以及相邻有效帧之间超过 `3.00deg` 的不可能角度跳变。绝对软限位 `121~208deg` 必须连续5个有效样本越界才会触发失能，单帧捕获抖动不会再关闭电机。状态输出中的 `fault` 会锁存最近故障（`0`正常、`1`编码器丢失、`2`绝对角、`3`相对角、`4`方向），`reject` 是累计拒绝的异常编码器样本数，`absbad` 是当前连续绝对角越界样本数。

## 串级 PID 与 A→B 测试

初始参数为：位置环 `Kp=3.50, Ki=0.08, Kd=1.00`，速度环
`Kp=0.80, Ki=0.10, Kd=0.03`。目标球速限制为 `20cm/s`，速度给定加速率为
`200cm/s²`，速度环摆角限制为 `±8deg`。这些是带安全限幅的硬件参数，实际装置仍需根据轨道摩擦、负载和相机速度噪声整定。

自动破静摩擦采用自适应启动角：小球向X正方向运动从 `-4.60deg` 开始，向X负方向运动从 `+4.80deg` 开始；一次补偿持续12个视觉帧仍无同向位移时，下一次增加 `0.25deg`，最大限制为 `±6.50deg`。一旦检测到同向位移 `0.05cm` 或同向速度 `0.30cm/s`，立即撤掉强制角度并恢复正常速度环和距离制动；若最大角仍无法启动，则停止重复补偿，重新发送目标或重启视觉闭环后才会重试。状态输出中的 `kick` 表示当前补偿状态，`events` 是触发次数，`boost` 是最近一次自适应启动角，`retry` 是升级级别，`block=1` 表示达到最大角仍未运动。

建议先做短距离测试：机构调平后依次发送 `Z`、`E`，用 `X-3` 设置 A 点并发送
`V`；小球在 A 点稳定后发送 `X+3`，观察 A→B 的加速、提前制动和停止过程。
确认方向与制动正确后再逐步扩大目标距离。任何异常立即发送 `S`。

## 版本与回退

3507和 MaixCAM2代码使用两个独立提交保存：

- 只回退3507：对3507提交执行 `git revert <commit>`
- 只回退 MaixCAM2：对 MaixCAM2提交执行 `git revert <commit>`
- 全部回退：按从新到旧顺序分别 `git revert` 两个提交

推荐使用 `git revert` 生成可追踪的回退记录，不使用破坏历史的强制重置。
